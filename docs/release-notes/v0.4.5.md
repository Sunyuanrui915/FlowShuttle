# Flow Shuttle v0.4.5 Release Notes

流梭 Flow Shuttle v0.4.5 修复了编辑器任务列表勾选时的页面跳转问题。

## 修复

- 勾选或取消勾选任务时，编辑区不再跳到先前的光标位置或开头，当前阅读位置保持不变。

---

## English

Flow Shuttle v0.4.5 fixes an editor scroll jump when toggling task-list checkboxes.

### Fixed

- Checking or unchecking a task no longer jumps to an earlier cursor position or the top of the editor. The current reading position stays in view.
