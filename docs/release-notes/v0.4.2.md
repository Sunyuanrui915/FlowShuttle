# Flow Shuttle v0.4.2 Release Notes

流梭 Flow Shuttle v0.4.2 聚焦两处桌面交互细节：系统托盘右键菜单现在能够更稳定、利落地显示和关闭；图片大图预览在放大后可以拖动查看，不再遗漏边缘内容。

## 修复

- 修复系统托盘右键菜单弹出时的闪烁，并优化菜单显示与关闭行为。

## 优化

- 图片大图预览在放大后支持拖动查看，可完整浏览图片边缘内容。

---

## English

Flow Shuttle v0.4.2 focuses on two desktop interaction details: the system-tray right-click menu now opens and closes more cleanly, and zoomed full-image previews can be dragged so edge content remains reachable.

### Fixed

- Fixed visible flashing when opening the system-tray right-click menu and refined its display and dismissal behavior.

### Improved

- Zoomed full-image previews can now be dragged so edge content remains reachable.
