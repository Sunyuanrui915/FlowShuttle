# Flow Shuttle v0.4.4 Release Notes

流梭 Flow Shuttle v0.4.4 新增编辑框内查找与替换，并让工具栏根据编辑区宽度自动调整。

## 新增

- 编辑框内查找与替换：点击工具栏搜索按钮或按 `Ctrl+F` 开始查找，支持匹配高亮、数量、前后跳转和区分大小写；按 `Ctrl+H` 展开替换，可替换当前项或全部匹配，全部替换支持一次撤销。工作项内容、每日记录、项目备忘录和报告编辑框均可使用。

## 优化

- 自适应编辑器工具栏：空间充足时直接显示工具；窗口缩小或参考栏展开后，放不下的格式工具按组进入带图标、文字和快捷键提示的“更多”下拉菜单。搜索与 AI 润色入口保持可见，宽度恢复后工具会回到原来的位置。

---

## English

Flow Shuttle v0.4.4 adds in-editor find and replace and a toolbar that adapts to the editor's available width.

### Added

- In-editor find and replace: use the toolbar search button or `Ctrl+F` for match highlighting, counts, navigation, and case-sensitive search. Press `Ctrl+H` to replace the current match or all matches; Replace all can be undone in one step. Available in work-item content, daily records, project memos, and report editors.

### Improved

- Adaptive editor toolbar: tools appear inline when space permits. Narrowing the window or opening the reference panel moves overflow formatting tools into a More dropdown with icons, labels, and shortcut hints. Search and AI Polish remain visible, and tools return to their original positions when space becomes available.
