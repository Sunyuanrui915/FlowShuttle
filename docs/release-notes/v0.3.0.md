# Flow Shuttle v0.3.0 Release Notes

流梭 Flow Shuttle v0.3.0 是一次覆盖全应用主要页面的全面 UI 升级。本次更新重新梳理了 Today、项目、报告、热力图、归档与设置页面的视觉层级和交互体验，并引入 Today 星座概览、星座热力图、报告编辑与编辑器背景等能力。

## 新增

- 日报、周报和月报支持在应用内编辑并保存；离开未保存内容时会进行确认。
- 编辑器支持切换背景，可在默认、云雾、森林和夜航样式之间选择。
- 设置页新增可展开的版本信息区域。

## 优化

- 全面更新 Today、项目、报告、热力图、归档与设置页面的视觉层级、间距和多分辨率适配。
- Today 页使用星座式概览呈现工作项，并通过星点、颜色和动画反馈已填写、阻碍与状态变化。
- 热力图使用统一的综合热度口径，以不同星座形态呈现每天的记录活跃程度，并优化当天摘要和月度数据概览。
- 优化项目与归档列表的信息可读性、阻碍标识和项目备忘录入口。
- 页签切换增加滑动反馈，状态选择菜单和常用提示样式同步优化。
- 更新简体中文、繁体中文与英文界面文案，并同步更新中英双语使用指南。

## English

Flow Shuttle v0.3.0 is a comprehensive UI upgrade across the application's main pages. It restructures the visual hierarchy and interactions in Today, Projects, Reports, Heatmap, Archive, and Settings, while introducing constellation-based views, report editing, and editor backgrounds.

### Added

- Added in-app editing and saving for daily, weekly, and monthly reports, including confirmation before leaving unsaved changes.
- Added selectable editor backgrounds: Default, Cloud Mist, Forest Whisper, and Night Voyage.
- Added an expandable version information section in Settings.

### Improved

- Refreshed visual hierarchy, spacing, and multi-resolution behavior across Today, Projects, Reports, Heatmap, Archive, and Settings.
- Reworked the Today overview as a constellation with star, color, and motion feedback for filled items, blockers, and status changes.
- Unified heatmap activity into one composite scale, represented daily activity with constellation shapes, and refined the selected-day and monthly summaries.
- Improved information density in project and archive lists, blocker indicators, and access to project memos.
- Added sliding feedback for tab changes and refined status menus and common prompts.
- Updated Simplified Chinese, Traditional Chinese, and English UI copy, together with the bilingual user guide.
